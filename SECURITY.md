# Sécurité de la version d'ethone

Cette politique concerne le fork [ethoneslop/skred](https://github.com/ethoneslop/skred). **ethone** contribue sous pseudonyme, à titre non professionnel. Il est responsable de ses ajouts, de leur maintenance et du suivi de la sécurité de cette version du service.

Les vidéos, les photos et les fichiers produits sont traités en local sur l'appareil. Le service ne les transmet à aucun serveur. L'enregistrement ou le partage du résultat reste à l'initiative de la personne qui utilise l'outil.

Pour signaler un bug ou un souci de sécurité concernant cette version, ouvre une [issue sur le fork d'ethone](https://github.com/ethoneslop/skred/issues), et non sur le dépôt d'origine. Indique la version utilisée, le navigateur ou l'appareil concerné et les étapes permettant de reproduire le problème, afin qu'ethone puisse le suivre et le traiter.

Les modifications apportées par ethone doivent être documentées par des commits sur ce fork. Les [mentions légales](mentions.html) et les [consignes de contribution](CONTRIBUTING.md) précisent sa participation.

# Security for ethone's version

This policy applies to the [ethoneslop/skred fork](https://github.com/ethoneslop/skred). **ethone** contributes under a pseudonym, in a non-professional capacity, and is responsible for the features and changes added to this fork, their maintenance, and security follow-up for this version of the service.

To report a bug or security concern affecting this version, open an [issue on ethone's fork](https://github.com/ethoneslop/skred/issues), rather than on the original repository. Include the version, browser or device, and steps to reproduce the problem so ethone can track and handle the report.

Changes made by ethone must be documented through commits on this fork. See the [legal notice](mentions.html) and [contribution guidelines](CONTRIBUTING.md) (in French).
