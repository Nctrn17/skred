Vérifier skred

Tu as raison de te méfier d'un outil qui touche à des vidéos de gens. Cette page ne te demande pas de nous croire : elle explique comment vérifier.

Ce que fait skred

La vidéo est analysée sur ton téléphone. Chaque visage trouvé est recouvert d'un carré noir plein, peint sur l'image avant qu'elle soit réenregistrée : le fichier produit ne contient plus le visage, ni flou ni caché.

Le lieu, la date et le modèle du téléphone, que les vidéos gardent souvent dans le fichier, sont retirés.

Pas de compte, pas de publicité, pas de mesure d'audience. Comme tout site, l'hébergeur (Cloudflare) voit qui se connecte à skred.fr. Il ne voit jamais les vidéos : elles ne quittent pas ton téléphone.

Vérifier sans rien installer

Le mode avion. Ouvre skred.fr, attends que la page soit chargée, puis passe en mode avion. Choisis une vidéo, masque-la, enregistre-la : tout marche sans réseau. Rien ne peut donc partir.

Le résultat. Avant de publier, regarde la vidéo masquée en entier, en avançant image par image sur les passages où il y a du monde.

Vérifier si tu sais coder

Le code est public, sous licence libre : github.com/Nctrn17/skred. Le code de skred servi par le site est le même fichier, lisible, sans rien de caché.

Aucune trace du visage. Le test test/test-sans-trace.mjs prend deux vidéos identiques sauf les visages, leur pose les mêmes masques et compare les fichiers produits : ils sont identiques octet pour octet. Le résultat ne dépend donc pas du visage, et aucun filigrane ne peut permettre de le retrouver.

Aucun envoi. La page interdit au navigateur de se connecter à un autre site que skred.fr. L'app Android n'a même pas la permission d'utiliser Internet.

Les bibliothèques. Les seuls fichiers compressés sont deux bibliothèques connues (ONNX Runtime et Mediabunny) et le modèle de détection (YuNet, d'OpenCV). test/verifier-tiers.sh vérifie qu'ils sont identiques aux versions officielles.

Ce que skred ne fait pas

Aucun outil ne trouve tous les visages à coup sûr : un visage de profil, caché en partie ou très petit peut être raté. Tu peux ajouter un masque à la main d'une touche sur l'image.

Le carré cache le visage, pas les vêtements, les tatouages, la démarche, le lieu ni la voix. Le son est gardé par défaut : coupe-le avec le bouton « Son » si des voix peuvent être reconnues.
